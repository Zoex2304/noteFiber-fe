Use case description - semua aktor (sesuai fungsional)
Berikut adalah penjabaran use case description berdasarkan kebutuhan fungsional yang sudah di tentukan sebelumnya. Setiap item fungsional dipetakan langsung ke dalam tabel.
 
Aktor: user in general
Tabel 1. Use case deskripsi: register
Nama use case
Register
Aktor
User (calon pengguna)
Deskripsi
Terdiri dari alur untuk mendaftarkan akun baru.
Pre-condition
Pengguna belum memiliki akun dan berada di halaman awal aplikasi.
Post-condition
Akun baru pengguna berhasil dibuat dan pengguna masuk ke dalam aplikasi (login).
Daftar akun baru
Aktor
Aplikasi
1. Buka aplikasi.
1. Menampilkan halaman login/awal.
2. Klik link "sign up".
2. Menampilkan halaman formulir registrasi.
3. Isikan data registrasi (misal: nama, email, password).
 
4. Klik tombol "daftar".
4. Memvalidasi data yang diinput.
 
5. Jika valid, membuat akun baru di sistem.
 
6. Menampilkan halaman workspace utama aplikasi (dalam keadaan login).
Alur alternatif:
- jika data yang dimasukkan tidak valid (email salah format, password lemah), aplikasi menampilkan pesan kesalahan.
- jika email sudah terdaftar, aplikasi menampilkan pesan kesalahan "email telah digunakan".

 
 
 
Tabel 2. Use case deskripsi: login
Nama use case
Login
Aktor
User
Deskripsi
Terdiri dari alur login menggunakan kredensial, login menggunakan provider eksternal, dan alur reset password.
Pre-condition
Pengguna sudah memiliki akun.
Post-condition
Pengguna berhasil masuk ke aplikasi dan aplikasi menampilkan halaman workspace utama.
Login menggunakan kredensial user
Aktor
Aplikasi
1. Buka aplikasi.
1. Menampilkan halaman login.
2. Isikan email dan password.
 
3. Klik tombol "login".
3. Mengecek kredensial (email dan password) valid atau tidak.
 
4. Jika kredensial valid, tampilkan halaman workspace utama.
Alur alternatif:
Jika email atau password yang dimasukkan salah, aplikasi akan menampilkan pesan kesalahan.
Login menggunakan provider (cth google)
Aktor
Aplikasi
1. Buka aplikasi.
1. Menampilkan halaman login.
2. Klik tombol "login dengan google" (atau provider lain).
2. Mengarahkan (redirect) ke halaman autentikasi provider (google).
3. Pilih akun google yang akan digunakan.
 
 
4. Menerima data autentikasi dari provider.
 
5. Memvalidasi data dan mengidentifikasi pengguna di sistem.
 
6. Menampilkan halaman workspace utama.
Alur alternatif:
Jika autentikasi provider gagal atau dibatalkan oleh pengguna, aplikasi kembali ke halaman login dan menampilkan pesan kesalahan.
Reset password
Aktor
Aplikasi
1. Buka aplikasi (di halaman login).
1. Menampilkan halaman login.
2. Klik link "lupa password"
2. Menampilkan halaman input email untuk reset password.
3. Isikan email pada kolom yang tersedia.
 
4. Klik tombol "kirim".
4. Mengecek email terdaftar di sistem atau tidak.
 
5. Mengirimkan email berisi link/instruksi reset password.
 
6. Menampilkan pesan konfirmasi "email reset telah dikirim".
7. Buka email dan klik link reset password.
7. Menampilkan halaman input password baru.
8. Isikan password baru dan konfirmasi password baru.
 
9. Klik tombol "simpan password baru".
9. Memvalidasi dan menyimpan password baru.
 
10. Menampilkan halaman login dengan pesan sukses.
Alur alternatif:
Jika email tidak terdaftar saat langkah 4, aplikasi menampilkan pesan "email tidak ditemukan".

Aktor
User
Deskripsi
Terdiri dari alur untuk melihat, mengubah data profil, dan menghapus akun.
Pre-condition
Pengguna harus sudah login ke aplikasi.
Post-condition
Data profil pengguna terperbarui, atau akun pengguna terhapus dari sistem.
Tampil informasi profil
Aktor
Aplikasi
1. Klik menu "profile" atau ikon akun.
1. Menampilkan halaman profil yang berisi data pengguna (nama, email, dll).
Alur alternatif:
-
Ubah data profil
Aktor
Aplikasi
1. Buka halaman "profile".
1. Menampilkan halaman profil.
2. Klik tombol "edit profil".
2. Menampilkan formulir edit data profil.
3. Ubah data pada kolom yang diinginkan (misal: nama).
 
4. Klik tombol "simpan".
4. Memvalidasi data baru.
 
5. Memperbarui data profil di database.
 
6. Menampilkan halaman profil dengan data terbaru dan pesan sukses.
Alur alternatif:
Jika data baru tidak valid, aplikasi menampilkan pesan kesalahan.
Hapus akun
Aktor
Aplikasi
1. Buka halaman "profile" atau "pengaturan akun".
1. Menampilkan halaman profil/pengaturan.
2. Klik tombol "hapus akun".
2. Menampilkan modal konfirmasi "apakah anda yakin ingin menghapus akun?".

4. Klik tombol "ya, hapus akun saya".
4. Memvalidasi password.
 
5. Menghapus data pengguna dari sistem.
 
6. Meng-logout pengguna dan menampilkan halaman login/awal.
Alur alternatif:
Jika konfirmasi password salah, aplikasi menampilkan pesan kesalahan.

Tabel 5. Use case deskripsi: notebook (folder)
Nama use case
Notebook
Aktor
User
Deskripsi
Alur mengelola notebook (folder) dan sub-notebook (sub-folder) melalui sidebar.
Pre-condition
Pengguna harus sudah login ke aplikasi dan sidebar navigasi file terlihat.
Post-condition
Data notebook (folder) milik pengguna terkelola.
Buat notebook baru
Aktor
Aplikasi
1. (opsional) klik notebook induk di sidebar (jika ingin membuat sub-notebook).
1. (opsional) menandai notebook induk sebagai lokasi aktif.
2. Klik tombol "buat notebook baru" (yang ada di sidebar ).
2. Menampilkan formulir/modal input nama notebook.
3. Isikan nama notebook.
 
4. Klik tombol "simpan" / "buat".
4. Memvalidasi nama notebook.
 
5. Menyimpan notebook baru ke sistem (di root, atau di dalam notebook induk yang dipilih).
 
6. Menampilkan notebook baru di sidebar tree .
Alur alternatif:
Jika nama notebook kosong atau tidak valid (misal: duplikat), aplikasi menampilkan pesan kesalahan.
Navigasi struktur notebook (di sidebar)
Aktor
Aplikasi
1. (otomatis) melihat struktur file di sidebar .
1. Menampilkan struktur tree notebook (folder) dan catatan di sidebar .
2. Klik ikon "expand" (misal: panah) di sebelah notebook (folder) di sidebar .
2. Memperluas (expand) tree di sidebar untuk menampilkan semua isinya (sub-notebook dan catatan).
Alur alternatif:
Jika notebook (folder) kosong, saat di-expand tidak menampilkan item apa pun di bawahnya.
Ubah nama notebook
Aktor
Aplikasi
1. Klik kanan atau klik ikon "opsi" pada notebook di sidebar .
1. Menampilkan menu konteks (opsi).
2. Klik tombol "ubah nama".
2. Menampilkan formulir/modal input nama baru.
3. Isikan nama notebook baru.
 
4. Klik tombol "simpan".
4. Memvalidasi nama baru.
 
5. Memperbarui nama notebook di sistem dan di sidebar .
Alur alternatif:
Jika nama baru kosong atau tidak valid, aplikasi menampilkan pesan kesalahan.
Hapus notebook
Aktor
Aplikasi
1. Klik kanan atau klik ikon "opsi" pada notebook di sidebar .
1. Menampilkan menu konteks (option dropdown – salah satu nya hapus).
2. Klik tombol "hapus".
2. Menampilkan modal konfirmasi "hapus notebook ini? Semua sub-notebook dan catatan di dalamnya juga akan terhapus.".
3. Klik tombol "ya, hapus".
3. Menghapus data notebook (dan isinya) dari sistem.
 
4. Menghapus notebook dari sidebar tree .
Alur alternatif:
Jika pengguna klik "batal", modal konfirmasi tertutup dan operasi penghapusan juga batal.

Tabel 8. Use case deskripsi: chatbot ai
Nama use case
Chatbot ai
Aktor
User - premium
Deskripsi
Alur untuk berinteraksi dengan chatbot ai.
Pre-condition
Pengguna sudah login dan memiliki status "premium".
Post-condition
Pengguna mendapatkan jawaban dari ai dan riwayat percapan tersimpan.
Buka interface chatbot ai serta muat history percakapan
1.klik tombol berbentuk icon bubble chat pada sidebar
1. Menampilkan modal (interface) chatbot ai
 
 
2. (otomatis) memuat dan menampilkan riwayat percakapan sebelumnya.
Alur alternatif:
- jika tidak ada riwayat, sidebar akan kosong.
Kiirim pertanyaan (prompt) dan nerima response
Aktor
Aplikasi
1. Buka interface chatbot ai.
 
2. Pilih sesi chat yang sudah ada (dari sidebar) atau buat percakapan baru (sesuai alur "membuat percakapan baru").
2. Menampilkan chat area yang aktif.
3. Fokus pada chat bar di bagian bawah chat area.
 
4. Ketikkan pertanyaan (prompt).
 
5. Tekan "enter" atau klik tombol "send" (ikon pesawat terbang) di chat bar.
5. Menampilkan prompt pengguna di chat area.
 
6. Memproses prompt ke model ai.
 
7. Menerima jawaban dari ai.
 
8. Menampilkan jawaban ai di chat area.
Alur alternatif:
- jika terjadi error saat memproses, aplikasi menampilkan pesan kesalahan.
 
 
Buat percakapan baru
1. Buka interface chatbot ai.
 
2. Klik tombol "new chat" di bagian kanan atas modal.
2. (otomatis) membuatkan workspace (chat area) yang baru.
 
3. Menampilkan pesan inisial (cth: "hi, how can i help you?") di chat area.
Alur alternatif:
- alur ini juga terjadi jika user membuka interface dan belum ada riwayat chat sama sekali.
